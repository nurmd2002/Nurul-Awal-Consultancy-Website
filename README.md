# Nurul-Awal-Consultancy-Website
Modern business website built with Next.js, React and Tailwind CSS for a Singapore halal consultancy. Features responsive design, reusable components, custom UI and production-ready deployment.


This project was designed and developed from the ground up using **Next.js**, **React**, and **Tailwind CSS**, with a strong emphasis on clean UI/UX, responsiveness, and maintainable component-based architecture.

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/nurul-awal-website.git
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```
http://localhost:3000
```
